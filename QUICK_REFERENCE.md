# Quick Color Reference - Altrum Inspired

## 🎨 Dark Backgrounds (Use Everywhere)
```
Main: #0A0A0A
Cards: #141414
Hover: #1A1A1A
```

## 🔴 Maroon Brand Colors (Use for CTAs & Accents)
```
Primary: #8B2F39  (Buttons)
Hover: #A13D47    (Button hover)
Deep: #6B1F2A     (Gradients)
Muted: #5A1A23    (Borders)
```

## 📝 Text Colors
```
Headings: #FFFFFF     (White)
Body: #A0A0A0         (Light gray)
Meta: #6B6B6B         (Muted)
```

---

## Quick Usage

### Button
```css
background: #8B2F39;
hover: #A13D47;
color: #FFFFFF;
```

### Card
```css
background: #141414;
border: #5A1A23 (30% opacity);
```

### Text
```css
heading: #FFFFFF;
body: #A0A0A0;
```
