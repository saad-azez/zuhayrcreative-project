# Quick Color Reference - Altrum Inspired

## 🎨 Dark Backgrounds (Use Everywhere)
```
Main: #0A0A0A
Cards: #141414
Hover: #1A1A1A
```

## 🔴 Custom Maroon Brand Colors (Use for CTAs & Accents)
```
Dark Maroon: #470015  (Primary brand)
Light Maroon: #800020 (Borders, titles)
Title Red: #DC143C    (Buttons, CTAs)
Footer: #38000E       (Footer, panels)
```

## 📝 Text Colors
```
Headings: #FFFFFF     (White)
Body: #A0A0A0         (Light gray)
Meta: #6B6B6B         (Muted)
```

---

## Quick Usage

### Button
```css
background: #DC143C (90% opacity);
hover: #DC143C (full);
color: #FFFFFF;
```

### Card
```css
background: #141414;
border: #800020 (30% opacity);
```

### Text
```css
heading: #FFFFFF;
body: #A0A0A0;
```
